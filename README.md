# DungeonHelper

DungeonHelper is a **ChatTriggers module for Hypixel SkyBlock** focused on **reducing crashes and instability in Dungeons**, especially issues related to **phasing blocks, desync, and chunk/block state errors**.

This module does **not** automate gameplay or provide combat advantages.  
Its only purpose is to **increase client stability** during dungeon runs.

---

## 🧱 What This Fixes

DungeonHelper targets common client-side issues such as:

- Crashes caused by **phasing blocks**
- Dungeon-related **desync / invalid block states**
- Instability during fast movement or teleporting
- Rare chunk / world loading edge cases

The goal is to **stop crashes before they happen** or safely recover when possible.
